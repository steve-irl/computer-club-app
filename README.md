# computer-club-app

Система управління комп'ютерним клубом: база даних (MariaDB) і веб-застосунок (Python, FastAPI) для керування робочими місцями, сесіями клієнтів, тарифами, бронюванням та замовленнями з бару.

Курсова робота з дисципліни «Організація баз даних».

## Що потрібно встановити

1. [Docker Desktop](https://www.docker.com/products/docker-desktop/) - обов'язково запущений (внизу зліва має бути статус Engine running)
2. [Git](https://git-scm.com/)

Більше нічого встановлювати не треба: база даних і веб-сервер запускаються в контейнерах.

## Запуск проєкту

1. Склонуйте репозиторій і зайдіть у папку проєкту:
   ```bash
   git clone https://github.com/steve-irl/computer-club-app.git
   cd computer-club-app
   ```
2. Запустіть усі сервіси:
   ```bash
   docker compose up -d --build
   ```
   Перший запуск може тривати кілька хвилин, бо Docker завантажує образи й встановлює залежності. Це нормально.
3. Переконайтеся, що працюють три контейнери:
   ```bash
   docker ps
   ```
   Мають бути: `computer_club`, `club_adminer`, `club_web`.

## Куди заходити після запуску

| Що | Адреса | Дані для входу |
|----|--------|----------------|
| Веб-застосунок (карта залу, сесії) | http://localhost:8000 | не потрібні |

Пряме підключення до бази (наприклад, з DBeaver чи VS Code): хост `127.0.0.1`, порт `3306`, користувач `club_user`, пароль `userclub`, база `computer_club`.

## Як користуватися застосунком

- На карті залу кольорами показано стан місць: зелений - вільно, червоний - зайнято, жовтий - заброньовано, сірий - на обслуговуванні.
- Щоб відкрити сесію: клікніть на зелене місце, оберіть клієнта і тариф, натисніть «Старт».
- Щоб закрити сесію: клікніть на червоне місце і натисніть «Завершити та списати кошти». Вартість розраховується автоматично, сума списується з балансу клієнта, місце стає вільним.

## База даних

Таблиці: `clients`, `halls`, `pc_specs`, `seats`, `tariffs`, `sessions`, `reservations`, `products`, `orders`.

Файли з папки `db` виконуються автоматично в алфавітному порядку при першому створенні бази.

## Робота з базою

### Скинути базу до початкового стану
Скрипти з папки `db` виконуються лише коли база порожня. Щоб база перечитала оновлені `.sql` файли, видаліть її дані й запустіть заново:
```bash
docker compose down -v
docker compose up -d --build
```

### Якщо хтось оновив код або структуру БД
```bash
git pull origin main
docker compose down -v
docker compose up -d --build
```

### Якщо створено нову таблицю або змінено структуру
Додайте SQL-код `CREATE TABLE` або `ALTER TABLE` у файл `db/01-schema.sql`.

### Зупинити проєкт
```bash
docker compose down
```

## Якщо щось не працює

- **Помилка `failed to connect to the docker API`** - Docker Desktop не запущений. Запустіть його, дочекайтеся статусу Engine running і повторіть команду.
- **Помилка `port is already allocated`** - порт зайнятий іншою програмою. Порти, які використовує проєкт: 3306 (база), 8000 (застосунок), 8081 (Adminer). Зупиніть програму, що займає порт, або змініть перше число в рядку `ports` у файлі `docker-compose.yml` (наприклад, `"8082:8080"`).
- **Сторінка localhost:8000 не відкривається** - перевірте `docker ps` і подивіться логи: `docker logs club_web`.
- **Таблиці порожні або їх немає** - один зі скриптів у папці `db` міг завершитися помилкою. Подивіться `docker logs computer_club`, потім скиньте базу командами з розділу вище.
